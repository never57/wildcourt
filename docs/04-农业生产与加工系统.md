# 文档四：农业生产与加工系统

> 版本：V0.1.0-alpha

## 4.1 设计原则

所有玩家种植数据完全一致，无省份加成，无身份加成。14种作物覆盖全部34省材料需求，生长时间从20分钟到12小时梯度分布，保证不同在线频率的玩家都能找到适合自己的节奏。

## 4.3 种植规则

| 规则 | 说明 |
| --- | --- |
| 初始农田 | 6块 |
| 最大农田 | 12块（庭院解锁进度4级） |
| 种植方式 | 点击空农田→弹出种子列表→选择→开始生长 |
| 种子来源 | 种子无法自产（收获作物不返还种子）；仅可通过商店购买、好友赠送、每日签到获得 |
| 生长阶段 | 4个阶段，每25%切换一次Sprite |
| 成熟提示 | 农田地块上方弹出浮动提示框，显示"可收获"气泡（成熟时持续浮动直至收获） |
| 浇水 | 可选操作，点击作物→宠物跑来浇水 |
| 施加化肥 | 化肥可立即完成生长（商店道具货架用邮券购买，1邮券=10份；活动偶尔赠送） |

## 4.5 钓鱼系统

| 规则 | 说明 |
| --- | --- |
| 解锁条件 | 玩家等级达到2级（等级系统详见文档三 3.5 经验值系统） |
| 鱼饵 | 钓鱼需消耗鱼饵（商店购买，详见文档九 9.7.1）；每次抛竿消耗 1 个鱼饵 |
| 每日上限 | 取消（无每日钓鱼次数限制，仅受鱼饵持有量约束） |
| 抛竿 | 点击水井→消耗 1 鱼饵抛竿，鱼饵立即进入 1 分钟生效计时 |
| 咬钩 | 鱼饵生效 1 分钟内，鱼按当前鱼饵的「咬钩概率」决定是否咬钩；并非每次抛竿必定上鱼 |
| 失效 | 1 分钟计时结束仍无鱼咬钩，鱼饵失效、本次钓鱼结束，鱼饵不返还 |
| 得鱼判定 | 鱼咬钩后进入持续点击收线阶段（连点维持收线进度）；收线进度满后按当前鱼饵的「出鱼权重」随机判定所得鱼种（见 4.5.1） |
| 离线 | 不支持离线钓鱼，需在线操作 |

### 4.5.1 鱼饵数据表

| ID | 名称 | 售价（庭贝） | 咬钩概率 | 出鱼权重（鲫鱼/鲤鱼/金鱼/草鱼/鲈鱼） | 说明 |
| --- | --- | --- | --- | --- | --- |
| B01 | 普通鱼饵 | 2 | 50% | 40/25/5/20/10 | 基础饵，便宜但咬钩率低 |
| B02 | 香精鱼饵 | 8 | 75% | 30/25/10/15/20 | 提升咬钩率与稀有鱼占比 |
| B03 | 秘制鱼饵 | 20 | 95% | 20/20/20/10/30 | 高咬钩率+高稀有率 |

> 出鱼权重为各鱼种的出现占比，五项之和恒为 100；稀有鱼（金鱼/鲈鱼）占比随鱼饵档位提升。清明活动提供限定鱼饵，咬钩概率与稀有鱼权重进一步上调（详见文档十三）。

## 4.9 加工规则

| 规则 | 说明 |
| --- | --- |
| 槽位 | 初始2个并行，最高5个 |
| 方式 | 点击加工台→选择配方→确认→开始倒计时 |
| 完成 | 倒计时结束→点击收取→产物进背包 |
| 离线 | 支持离线，后台计时 |
| 加速 | 消耗邮券可立即完成加工CD（邮券详见文档九 9.1.1） |
| 取消 | 支持取消，但已投入原料不返还（损失由玩家承担，避免误操作浪费） |
| 产物交易 | 加工产物不可出售（不换庭贝），仅用于非遗制作（文档六）或赠送给好友（文档八）；原始作物可直接出售换庭贝（文档九 9.2） |
