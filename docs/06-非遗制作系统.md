# 文档六：非遗制作系统

> 版本：V0.1.0-alpha

## 6.1 设计原则

34省各1种专属非遗，所有玩家均可制作所有省份的非遗，无身份限制，材料消耗一致。非遗是社交的核心流通物——派遣时携带、回赠时附送、图鉴收集的目标。

## 6.3 非遗制作规则

| 规则 | 说明 |
| --- | --- |
| 制作地点 | 工坊 |
| 身份限制 | 无，所有玩家可制作所有34省非遗 |
| 材料消耗 | 所有玩家一致，无减免 |
| 制作时间 |玩家完成互动小游戏的实际耗时，无固定值（见 6.4） |
| 互动环节 | 制作时进入该非遗专属互动小玩法，互动完成即产出物品 |
| 取消 | 互动小游戏进行中可随时取消制作，**返还100%材料（全部退回）**，不消耗材料 |
| 完成 | 产物进背包，用于派遣/回赠（**不可放入展示柜**） |


## 6.4 非遗互动小玩法机制

> 非遗制作的核心目标是**引导玩家动手去做**——让玩家在轻松、无压力的过程中体验 34 省非遗的手艺乐趣，而非比拼技巧或评分。每个非遗在制作时插入一段玩家亲自操作的互动小玩法，上手即玩；**无论制作的成品样貌如何，完成即算做完，成品不做任何评分**，直接入背包。

### 6.4.1 机制总述

- 玩家集齐材料 → 点击"制作" → 进入该非遗专属的**互动小玩法**环节（不是空等）。
- 玩法由 `miniGameType` 决定类型（如 `cut`/`carve`/`embroider`…），由 `template`/`hint` 提供该非遗专属的素材与提示（见 6.4.4）。
- 互动完成即直接入背包——**不再有固定制作时间或"定型"倒计时**，总耗时完全取决于玩家在互动小游戏里的操作时长（手快手慢、步骤多少都算在内）。
- **引导玩家制作（核心取向）**：非遗制作以"降低门槛、鼓励动手"为导向，而非考技巧/评分——难度从⭐单步带引导递进到⭐⭐⭐⭐精细无引导，循序渐进；低难度提供虚线引导与吸附，降低上手门槛；互动中随时可取消并全额返还材料，零成本试错；做完即点亮图鉴，以收集驱动玩家探索全部 34 省。


### 6.4.2 互动玩法类型与 34 省映射

| 类型 | 核心操作 | 对应非遗（ID） |
| --- | --- | --- |
| cut（裁剪） | 在纸/皮上按提示或自由裁出轮廓，贴合度反馈 | 蔚县剪纸NF01、桦树皮工艺品NF06 |
| carve（雕刻/刻版） | 沿模板路径运刀，路径贴合度反馈 | 东阳木雕NF08、岫岩玉雕NF04、贺兰石砚NF26、綦江版画NF31 |
| embroider（刺绣走线） | 沿绣样落针走线，针脚均匀度反馈 | 苏绣NF07、汉绣NF14、湘绣NF15、粤绣NF16、顾绣NF30 |
| weave（经纬编织） | 按节奏穿插经纬，对位准确度反馈 | 壮锦NF17、黎锦NF18、蜀锦NF19、傣族织锦NF21、艾德莱斯绸NF27、藏毯NF22 |
| paint（填色/彩绘） | 在轮廓内上色，不出界/不溢出反馈 | 农乐舞面具NF05、敦煌壁画NF24、热贡唐卡NF25、潍坊风筝NF12、杨柳青年画NF29 |
| shape（塑形/拉坯） | 塑出形状或拉坯，对称/轮廓贴合反馈 | 凤翔泥塑NF23、钧瓷NF13、景德镇瓷器NF11、脱胎漆器NF10 |
| brush（刷涂均匀） | 反复刷漆/刷油，覆盖均匀度反馈 | 平遥推光漆器NF02、美浓油纸伞NF34（刷桐油） |
| assemble（组装/对位） | 拼接部件或掐丝点蓝，对位准确度反馈 | 蒙古族马头琴NF03、苗族银饰NF20、景泰蓝NF28、美浓油纸伞NF34（制骨） |
| mix（调配） | 按配比混合/冲调，比例准确度反馈 | 港式奶茶NF32、土生葡人美食NF33 |

> 同一 `miniGameType` 因各自 `template`/`hint`/难度不同，玩家体感各异（如剪纸剪"窗花"、版画刻"生肖"），即实现"每个非遗都有独特小玩法"。

### 6.4.3 示例：蔚县剪纸（cut 裁剪）

玩家进入剪纸台，界面给出一张红纸与一组**提示轮廓**（如"福"字窗花半透明模板）：
- 自由裁剪模式：玩家用手指/鼠标沿模板边缘拖动裁剪，软件实时计算裁剪路径与模板的贴合度。
- 提示辅助：低难度（⭐）提供虚线引导与吸附；高难度仅给参考图，靠玩家手感。
- 完成：无论贴合高低都能剪出窗花（边缘毛糙/局部断开也可完成），小游戏只提供手感乐趣，不影响成品。

### 6.4.4 配置字段

每个非遗在 `Config_Nonfiction` 增加 `miniGameType`（玩法类型）与 `template`（素材/提示配置，JSON）。详见文档十六 Sheet7。

## 6.5 非遗制作步骤（Lua驱动示例）

```lua
-- 美浓油纸伞的制作步骤定义
NF_美浓油纸伞 = {
    provinceId = 34,
    name = "美浓油纸伞",
    difficulty = 4,
    materials = {
        {itemId = "竹片", count = 4},
        {itemId = "构树皮纸", count = 3},
        {itemId = "桐油", count = 2}
    },
    steps = {
        {name = "劈竹", time = 30, anim = "craft_hammer", desc = "将竹子劈成细条做伞骨"},
        {name = "制伞骨", time = 60, anim = "craft_assemble", desc = "将竹条组装成伞骨结构"},
        {name = "糊纸", time = 60, anim = "craft_paint", desc = "在伞骨上糊上构树皮纸"},
        {name = "刷桐油", time = 90, anim = "craft_brush", desc = "反复刷上桐油防水"}
    },
    miniGameType = "assemble",  -- 互动玩法类型（见 6.4.2）
    template = {               -- 互动素材/提示配置（见 6.4.4）
        parts = {"伞骨", "伞面", "伞柄"},
        hint = "按步骤拼接伞骨即可完成，对位准确手感更佳"
    }
}
```
