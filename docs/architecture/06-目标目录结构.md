## 6.3 配置表（Excel → Lua，17 张）

```
config-excel/ 或上游表格库（策划维护）
├── Sheet1_Provinces     34 省（id/name/region/mapColor）
├── Sheet2_Cities        300~400 城市（provinceId/pinyin）
├── Sheet3_Crops         14 作物 C01~C14
├── Sheet4_Fish          鱼类 F01~F05
├── Sheet4.1_Bait        鱼饵 B01~B03（hookRate/weight）
├── Sheet5_ProcessRecipes 8 条加工配方
├── Sheet6_FoodRecipes   10 食谱（品质由烹饪运行时结算）
├── Sheet7_Nonfictions   34 省非遗 NF01~NF34（miniGameType + template JSON）
├── Sheet8_HospitalityWeights 好客值权重
├── Sheet9~12_Shop       商店（种子/材料/道具/鱼饵）
├── Sheet13_FriendInteractions 好友交互
├── Sheet14_StealMechanics     偷菜机制
├── Sheet15_Badges       徽章
├── Sheet16_YardUnlock   庭院解锁（等级容量）
└── Sheet17_PlayerLevel  玩家等级曲线

导出链路：Excel2Lua.py 校验 → LuaScripts/Config/ → AB → StreamingAssets/config/ → 客户端加载；服务端同源读取
```

## 6.4 目录增量建议（相对当前现状）

1. **client**：`Scripts/` 各子目录目前只有 `.gitkeep`，建议按本文档 6.1 顺序填充：先 Core（GameManager/EventBus/LuaManager）→ Net（Protocol/Handler/WebSocket）→ Gameplay 各系统 → UI。
2. **server**：三个项目目前仅目录，建议按 02-服务端架构.md 的顺序实施：`WlidCourt.Data`（DbContext+Entities+迁移）→ `Utils` → `Services` → `Jobs/Hubs/Middleware` → `Controllers` → `Program.cs`。
3. **配置表**：Sheet16（YardUnlock）与 Sheet17（PlayerLevel）是玩家等级/庭院容量实现的前置依赖，优先产出。
