## 1.3 核心玩法一句话定义

玩家在自己的庭院里种地、加工、制作非遗、招待来访宠物→派遣宠物携带本省非遗外出拜访异地玩家→收到回赠后可加好友→互访对方庭院、偷菜、喂食、聊天。

## 1.4 核心玩法循环

| 阶段 | 行为 | 场所 | 产出 |
| --- | --- | --- | --- |
| 建造 | 摆放建筑、布置装饰 | 庭院 | 个性化空间 |
| 生产 | 种地/钓鱼/加工/制作非遗 | 庭院 | 农产品/材料/非遗 |
| 经营 | 制作口粮、放入食物盆 | 厨房/食物盆 | 招待用食物 |
| 社交·派遣 | 选择省份城市、写信托物 | 地图界面 | 宠物外出 |
| 社交·接收 | 被访问时自动消耗食物 | 食物盆 | 收到信件/非遗 |
| 反馈 | 收取回赠、解锁图鉴徽章 | 信箱/图鉴 | 收集进度 |
| 深化 | 加好友、互访、偷菜、喂食 | 好友庭院 | 社交关系 |

## 1.11 核心原则（红线）

| 原则 | 说明 |
| --- | --- |
| 台湾是中国第35个省级行政区 | 与其他34省完全平等，不可省略、不可单列 |
| 回赠为玩家主动选择 | 非概率判定，不做"回赠率"数值 |
| 省份无数值加成 | 所有玩家生产数据一致，省份仅为身份标识 |
| 庭院无评分系统 | 装饰纯审美表达，不影响任何数值 |
| 庭贝多来源获取 | 售卖农产品/每日签到/活动/小游戏均可获得，设每日上限控制通胀 |
