# 文档二：省份身份与地图系统

> 版本：V0.1.0-alpha

## 2.1 设计意图

省份和城市仅作为玩家的身份标识和派遣目的地的选择器，不参与任何数值计算。

## 2.2 首次进入流程

| 步骤 | 界面 | 交互 | 反馈 |
| --- | --- | --- | --- |
| 1 | Logo画面 | 自动播放 | 手绘信封+邮票动画，2秒后自动进入下一步 |
| 2 | 资源加载 | 进度条 | 底部显示"正在准备你的庭院…"+百分比 |
| 3 | 中国地图 | 手绘地图全屏显示 | Q版圆润线条勾勒省界，各省糖果色平涂 |
| 4 | 点击省份 | 点击地图任意省份 | 该省轮廓发光高亮，右侧滑出城市列表面板 |
| 5 | 选择城市 | 城市列表点击/搜索 | 选中城市蓝色高亮，底部显示确认信息 |
| 6 | 确认 | 点击"确认"按钮 | 播放过场动画（快递员单车送信封） |
| 7 | 进入庭院 | 过场动画结束 | 首次进入有新手游玩引导|

## 2.3 中国地图界面规范

| 元素 | 规范 |
| --- | --- |
| 地图风格 | Q版手绘线条，各省糖果色平涂（粉/蓝/绿/黄等） |
| 省界线条 | 粗细3px，深灰，圆润可爱描边 |
| 选中态 | 该省轮廓发光（外发光+5px模糊），颜色提亮30% |
| 未选中态 | 正常淡彩，hover时微亮 |
| 城市列表面板 | 从右侧滑入，宽度30%屏幕，背景圆点可爱纹理 |
| 城市列表排序 | 默认按拼音排序，可切换笔画排序 |
| 搜索框 | 顶部，输入城市名关键字实时过滤 |
| 34省排列 | 按地理大区分组：华北/东北/华东/华中/华南/西南/西北/港澳台 |

## 2.6 省份/城市的用途清单

| 用途 | 说明 | 是否影响数值 |
| --- | --- | --- |
| 玩家头像下方显示 | "河北·石家庄" | 否 |
| 派遣目的地选择 | 选省份→选城市→确认 | 否 |
| 好友列表筛选 | 按省份/城市筛选好友 | 否 |
| 图鉴收集维度 | "已访问15个省/42个城市" | 否 |
| 活动条件 | "河北省玩家专属活动" | 否（仅营销） |
| 信件内容 | "有只来自河北的猫…" | 否（仅文案） |

## 2.7 派遣时的地图选择交互

| 步骤 | 界面 | 交互 |
| --- | --- | --- |
| 1 | 点击"派遣" | 弹出手绘中国地图（半屏浮层） |
| 2 | 点击目标省份 | 该省高亮+右侧弹出城市列表 |
| 3 | 选择城市（可选） | 不选则随机该省内城市 |
| 4 | 点击"确认目的地" | 关闭地图浮层，返回派遣界面 |
| 5 | 继续选择非遗/写信 | 正常派遣流程 |

与首次进入的区别：派遣时不弹出省份卡片，点击省份直接出城市列表，选完直接返回派遣界面，全程无缝衔接。
