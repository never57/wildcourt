# 文档三：庭院建造系统

> 版本：V0.1.0-alpha

## 3.1 设计意图

庭院是生产的场所、经营的载体、社交的门面、庭贝的最终出口。但不做评分系统，不做主题包，不做布局加成。装饰纯粹为了好看和玩家的自我表达，不影响任何数值。玩家怎么摆都行，摆得好看是审美问题不是数值问题。

## 3.2 庭院功能定位

| 功能 | 说明 | 对应系统 |
| --- | --- | --- |
| 生产场所 | 种地/钓鱼/加工/制作非遗 | 农业/加工/非遗 |
| 经营场所 | 厨房做口粮/食物盆招待 | 口粮/好客值 |
| 展示场所 | 展示柜陈列非遗 | 图鉴 |
| 社交门面 | 好友互访时看到的就是庭院 | 好友 |
| 庭贝出口 | 卖农产品/签到/活动/小游戏赚的庭贝花在装饰上 | 商店 |

## 3.3 固定基底（不可改变）

| 元素 | 初始表现 | 是否可改 |
| --- | --- | --- |
| 地面 | 草地纹理 | 否（后续可通过全局装饰道具局部覆盖） |
| 围墙 | 木栅栏 | 否 |
| 天空 | 渐变卡通色+飘动云朵 | 否 |
| 大门 | 木门 | 否 |

## 3.4 固定建筑一览

| 建筑 | 功能 | 初始等级 | 最高等级 | 升级条件 | 升级效果 |
| --- | --- | --- | --- | --- | --- |
| 住宅 | 宠物休息/升级/查看属性 | 1（茅屋） | 3（楼房） | 庭院解锁进度 | 纯外观变化 |
| 工坊 | 制作非遗 | 1（木棚） | 3（琉璃瓦工坊） | 庭院解锁进度 | 纯外观变化 |
| 厨房 | 制作口粮 | 1（土灶） | 3（雕花木灶台） | 庭院解锁进度 | 纯外观变化 |
| 加工台 | 加工材料 | 1（木桌·1槽位） | 3（石台·5槽位） | 庭院解锁进度 | 槽位+外观 |
| 信箱 | 收发信件 | 1（木箱） | 3（雕花木箱） | 庭院解锁进度 | 容量+外观 |
| 展示柜 | 陈列非遗 | 1（木架·3格） | 3（博古架·9格） | 庭院解锁进度 | 格数+外观 |
| 食物盆 | 招待来访宠物 | 1（陶碗·10份） | 3（青花瓷缸·20份） | 庭院解锁进度 | 容量+外观 |
| 水井 | 装饰+钓鱼功能 | 1（土井） | 3（石井） | 商店购买 | 外观+钓鱼 |

升级只改外观和容量/槽位上限，不改变生产速度、食物品质等任何数值。

| 进度等级 | 农田数 | 加工槽位 | 食物盆容量 | 装饰上限 | 展示柜格数 | 信箱容量 | 解锁条件 |

| 1级（初始） | 6 | 2 | 10 | 50 | 3 | 20 | 初始 |

## 3.8 摆放规则

| 规则 | 说明 |
| --- | --- |
| 坐标系 | 斜45°等轴测，X轴向右下，Y轴向右上 |
| 网格 | 1单位=1米，所有装饰Snap到1×1网格 |
| 旋转 | 支持0°/90°/180°/270° |
| 渲染顺序 | 按Y坐标排序，Y越大越靠后，近下远上自动遮挡 |
| 不可重叠 | 同一网格只能放1个物件 |
| 边界限制 | 不可超出庭院围墙范围 |
| 尺寸适配 | 大于1×1的物件占多个网格，需全部空余才可放置 |

## 3.9 编辑模式交互

| 操作 | 交互方式 | 反馈 |
| --- | --- | --- |
| 进入编辑 | 点击右下角"编辑"按钮 | 半透明网格浮现，底部滑出装饰列表 |
| 选择装饰 | 点击装饰列表中的图标 | 图标高亮，光标变为该装饰预览 |
| 放置 | 拖拽到庭院，松手 | 绿色=可放，红色=不可放 |
| 移动 | 点击已放置装饰→"移动"→拖到新位置 | 原位置空出，新位置占格 |
| 旋转 | 点击已放置装饰→"旋转" | 顺时针90°，实时预览 |
| 删除 | 点击已放置装饰→"删除" | 弹出确认框→确认后移除→庭贝不返还 |
| 查看详情 | 双击已放置装饰 | 弹出名称+获取方式 |
| 完成 | 点击"完成" | 保存布局→退出编辑→重新计算渲染顺序 |
| 撤销 | Ctrl+Z | 回退上一步，最多50步 |
| 重做 | Ctrl+Y | 前进到下一步，最多50步 |
| 保存方案 | 点击"方案"→选择1/2/3 | 保存当前布局到对应方案槽 |
| 切换方案 | 点击"方案"→选择已保存方案 | 加载对应布局，替换当前 |

## 3.11 好友互访时的庭院

| 操作 | 交互 | 限制 |
| --- | --- | --- |
| 进入好友庭院 | 好友列表点击→"访问庭院" | 无限制 |
| 查看布局 | 自由拖拽/双指缩放 | 无限制 |
| 点击作物 | 弹出"偷取"按钮 | 每作物每天1次 |
| 点击宠物 | 弹出"喂食"按钮 | 每只每天3次 |
| 点击展示柜 | 查看好友非遗收集 | 显示名称/详情/解锁时间 |
| 点击信箱 | 查看好友收发数量 | 隐私保护，不看内容 |
| 点击装饰 | 查看装饰详情 | 名称/售价/获取方式 |
| 点击空白 | 弹出好友信息面板 | 昵称/省份城市/等级 |

## 3.12 去掉的内容（V0.1.0-alpha变更记录）

| 原内容 | 移除原因 |
| --- | --- |
| 庭院评分系统 | 装饰不应影响玩法数值 |
| 布局加成组合 | 同上 |
| 主题包系统（苏式/川西/闽南/四合院） | 改为装饰包，纯外观，不叫主题包 |
| 庭院评分×0.5计入好客值 | 好客值仅反映招待质量 |
| 庭院等级（含数值解锁） | 改为"庭院解锁进度"，条件透明 |
| 装饰评分数值 | 装饰不再有评分属性 |
