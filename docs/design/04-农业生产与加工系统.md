# 文档四：农业生产与加工系统

> 版本：V0.1.0-alpha

## 4.1 设计原则

所有玩家种植数据完全一致，无省份加成，无身份加成。14种作物覆盖全部34省材料需求，生长时间从1小时到7小时梯度分布，保证不同在线频率的玩家都能找到适合自己的节奏。

## 4.3 种植规则

| 规则 | 说明 |
| --- | --- |
| 初始农田 | 6块 |
| 最大农田 | 12块（庭院解锁进度4级） |
| 种植方式 | 点击空农田→弹出种子列表→选择→开始生长 |
| 种子来源 | 种子无法自产（收获作物不返还种子）；仅可通过商店购买、好友赠送、每日签到获得 |
| 生长阶段 | 4个阶段，每25%切换一次Sprite |
| 成熟提示 | 农田地块上方弹出浮动提示框，显示"可收获"气泡（成熟时持续浮动直至收获） |
| 浇水 | 可选操作，点击作物→宠物跑来浇水 |
| 施加化肥 | 化肥可立即完成生长（商店道具货架用邮券购买，1邮券=10份；活动偶尔赠送） |

## 4.5 钓鱼系统

| 规则 | 说明 |
| --- | --- |
| 解锁条件 | 玩家等级达到2级（等级系统详见文档三 3.5 经验值系统） |
| 每日上限 | 10次 |
| 方式 | 点击水井→抛竿→鱼咬钩→进入持续点击收线阶段（连点维持收线进度）→按概率得鱼 |
| 得鱼判定 | 鱼咬钩后玩家持续点击收线，点击频率影响收线进度；收线进度满后按该鱼基础概率（见4.6）判定是否得鱼 |
| 离线 | 不支持离线钓鱼，需在线操作 |

## 4.9 加工规则

| 规则 | 说明 |
| --- | --- |
| 槽位 | 初始2个并行，最高5个 |
| 方式 | 点击加工台→选择配方→确认→开始倒计时 |
| 完成 | 倒计时结束→点击收取→产物进背包 |
| 离线 | 支持离线，后台计时 |
| 加速 | 消耗邮券可立即完成加工CD（邮券详见文档九 9.1.1） |
| 取消 | 支持取消，但已投入原料不返还（损失由玩家承担，避免误操作浪费） |
