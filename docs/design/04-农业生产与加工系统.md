# 文档四：农业生产与加工系统

> 版本：V0.1.0-alpha

## 4.1 设计原则

所有玩家种植数据完全一致，无省份加成，无身份加成。14种作物覆盖全部35省材料需求，生长时间从1小时到7小时梯度分布，保证不同在线频率的玩家都能找到适合自己的节奏。

## 4.3 种植规则

| 规则 | 说明 |
| --- | --- |
| 初始农田 | 6块 |
| 最大农田 | 12块（庭院解锁进度4级） |
| 种植方式 | 点击空农田→弹出种子列表→选择→开始生长 |
| 生长阶段 | 4个阶段，每25%切换一次Sprite |
| 成熟提示 | 成熟时闪光+浮动动画+屏幕通知 |
| 枯萎规则 | 成熟后2小时未收获→枯萎→需点击清除→才能重种 |
| 浇水 | 可选操作，点击作物→宠物跑来浇水→好感度+1/次/天 |
| 加速 | 加速券可立即完成生长（商店购买20庭贝） |
| 批量操作 | 长按农田→"全部收获""全部种植"快捷按钮 |

## 4.5 钓鱼系统

| 规则 | 说明 |
| --- | --- |
| 解锁条件 | 拥有水井装饰（商店购买200庭贝） |
| 每日上限 | 10次 |
| 方式 | 点击水井→进入QTE界面→水波纹扩散时点击→成功得鱼 |
| QTE判定 | 点击时机分Perfect/Good/Miss三档，Perfect必得鱼，Good概率得鱼，Miss鱼逃跑 |
| 离线 | 不支持离线钓鱼，需在线操作 |
