## 5.2 制作规则

| 规则 | 说明 |
| --- | --- |
| 制作地点 | 厨房 |
| 方式 | 点击厨房→选择食谱→确认→开始制作 |
| 材料不足 | 红色提示缺口数量，不可制作 |

| 食物盆满 | 提示"食物盆已满，请先消耗一些" |

| 品质 | 食物品质由食谱决定（一般/良好/优秀/极佳） |

## 5.4 好客值公式

```
好客值 = 200（基础分）
       + 食物品质分（平均品质 × 50）
       + 食物丰富度分（种类数 × 30）
       + 连续招待分（连续天数 × 10，上限100）
       + 回访加分（上次被回赠 +100，持续3天）
       + 活跃度加分（今日在线 +150 / 7日在线 +100）
       + 好友加成（有好友 +50）
       + 随机扰动（0~30）
```

## 5.5 好客值因子权重表

| 因子 | 权重 | 计算方式 | 最大值 | 说明 |
| --- | --- | --- | --- | --- |
| 基础分 | - | 固定200 | 200 | 保底值 |
| 食物品质 | 50 | 平均品质×50 | 250（极佳=5×50） | 鼓励做高品质食物 |
| 食物丰富度 | 30 | 种类数×30 | 120（4种全有） | 鼓励多样化 |
| 连续招待 | 10 | 连续天数×10 | 100 | 鼓励每日上线 |
| 回访加分 | 100 | 被回赠后+100 | 100 | 持续3天 |
| 今日在线 | 150 | 当天登录过 | 150 | 鼓励当日活跃 |
| 7日在线 | 100 | 7天内有登录 | 100 | 鼓励持续活跃 |
| 好友加成 | 50 | 有≥1好友 | 50 | 鼓励社交 |
| 随机扰动 | - | 0~30随机 | 30 | 防止完全固化 |

好客值上限：约1110分（全满状态）
好客值下限：200分（基础分，不扣到负数）

## 5.6 好客值衰减规则

| 条件 | 惩罚 | 说明 |
| --- | --- | --- |
| 连续未招待 | -10/天 | 从最后一次有宠物来访算起 |
| 食物盆空>24h | -50 | 一次性惩罚 |
| 7日未登录 | -100 | 一次性惩罚 |
| 被偷菜（非好友） | -5/次 | 鼓励保持在线 |

## 5.7 好客值的作用

| 用途 | 说明 |
| --- | --- |
| 匹配权重 | 按好客值降序排列候选庭院 |
| 排行榜 | 每周好客值TOP100（分省排行） |
| 活动条件 | "好客值>500解锁XX活动" |
| 成就 | "累计好客值达到10000" |
