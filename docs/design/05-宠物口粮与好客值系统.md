## 5.2 制作规则

| 规则 | 说明 |
| --- | --- |
| 制作地点 | 厨房 |
| 方式 | 点击厨房→选择食谱→确认→进入【烹饪小游戏】→结算品质→完成（流程见 5.2.1） |

### 5.2.1 烹饪小游戏（火候与调味）

确认食谱后进入烹饪界面，分两个阶段，结算出最终成品品质（**而非由食谱决定**）。

**阶段一：控火候**
- 界面显示一段"火候槽"（0~100），目标"完美火候区"（如 60~80）以绿色高亮。
- 锅随时间自动升温，火候指针持续右移；玩家通过点击"翻动/减火"按钮压制升温、或停手放任升温，使指针停在理想区间。
- 玩家点击"起锅"结束本阶段，按指针落点判定：
  - 落在完美区 → **火候完美**
  - 低于完美区（还没熟透）→ **火候不足（生）**
  - 冲过红线（超过完美区上限）→ **火候过度（糊）**

**阶段二：撒盐**
- 进入调味环节，界面显示"盐量槽"（0~100），目标"适中区"（如 40~60）以绿色高亮。
- 玩家连续点击"撒盐"按钮，每点一次盐量 +固定值，需把盐量控制在适中区后点击"完成"。
- 按最终盐量判定：
  - 落在适中区 → **调味适中**
  - 低于适中区 → **偏淡（没味）**
  - 高于适中区 → **偏咸（齁）**

### 5.2.2 品质结算矩阵

火候与调味两个维度的结果组合，决定最终品质（5 档）：

| 火候 \ 调味 | 适中 | 偏淡 | 偏咸 |
| --- | --- | --- | --- |
| 完美 | 极佳 | 良好 | 良好 |
| 不足（生） | 一般 | 失败 | 失败（黑暗料理） |
| 过度（糊） | 一般 | 失败 | 失败 |

- **极佳 / 优秀 / 良好 / 一般**：正常可食用，按品质享受好客值加成。
- **失败（黑暗料理）**：火候与调味双崩（生+淡 / 糊+咸等），宠物不愿吃，好客值品质分计 0。

### 5.2.3 品质系数

各品质对应的好客值品质分（用于 5.4 好客值公式"平均品质 × 50"）：

| 品质 | 好客值品质分 |
| --- | --- |
| 极佳 | 5 |
| 优秀 | 4 |
| 良好 | 3 |
| 一般 | 2 |
| 失败 | 0 |

> 好客值公式中"平均品质 × 50"仍按上表品质分（极佳=5 … 失败=0）计入；失败的黑暗料理不贡献品质分（见 5.4 / 5.5）。

## 5.4 好客值公式

```
好客值 = 200（基础分）
       + 食物品质分（平均品质 × 50）
       + 连续招待分（连续天数 × 10，不设上限）
       + 回访加分（上次被回赠 +100，持续3天）
       + 每日在线加分（当日登录 +150）
       + 好友加成（有好友 +50）

> 好客值**不设上限**，可随连续招待天数等因子持续增长；仅基础分 200 作为下限保底（衰减不扣到负数）。
```

## 5.5 好客值因子权重表

| 因子 | 权重 | 计算方式 | 说明 |
| --- | --- | --- | --- |
| 基础分 | - | 固定200 | 保底值，衰减不扣到负数 |
| 食物品质 | 50 | 平均品质×50（极佳=5×50=250，源自品质档位物理封顶，非人为上限） | 鼓励做高品质食物 |
| 连续招待 | 10 | 连续天数×10 | 不设上限，鼓励每日上线 |
| 回访加分 | 100 | 被回赠后+100 | 持续3天 |
| 每日在线 | 150 | 当天登录过 | 鼓励当日活跃 |
| 好友加成 | 50 | 有≥1好友 | 鼓励社交 |

好客值不设上限：除食物品质受品质档位自然封顶（250）外，其余因子均无最大值限制，可随连续招待天数等持续增长。
好客值下限：200分（基础分，不扣到负数）。

## 5.8 宠物来访吐槽

异地宠物来访吃掉食物盆里的口粮时，按该份口粮的**结算品质**触发对应吐槽台词（触发节点见文档七 7.x 宠物来访食用环节）。吐槽仅为趣味表现，不影响好客值数值，但会作为日报弹窗文案的一部分（文档七 日报弹窗）。

| 品质 | 宠物态度 | 吐槽示例 |
| --- | --- | --- |
| 极佳 | 满足 | "哇！这简直是米其林宠物餐，汪~绝了！" |
| 优秀 | 喜欢 | "外酥里嫩、咸淡刚好，今天走运了！" |
| 良好 | 接受 | "嗯……能吃，谢谢款待啦。" |
| 一般（生） | 嫌弃 | "这……夹生的吧？我牙口没那么好。" |
| 一般（糊） | 嫌弃 | "焦了焦了，苦味直冲天灵盖。" |
| 一般（淡） | 嫌弃 | "一点味道都没有，你是忘了放盐？" |
| 一般（咸） | 嫌弃 | "咸得我直喝水，盐不要钱啊？" |
| 失败（生+淡） | 吐槽 | "又生又没味，你认真的？（斜眼）" |
| 失败（糊+咸） | 吐槽 | "黑乎乎还齁咸，这是黑暗料理吧！退退退！" |

> 吐槽文案池可按省份 / 宠物性格扩展，以上为默认通用台词。
