# 文档六：非遗制作系统

> 版本：V0.1.0-alpha

## 6.1 设计原则

35省各1种专属非遗，所有玩家均可制作所有省份的非遗，无身份限制，材料消耗一致。非遗是社交的核心流通物——派遣时携带、回赠时附送、图鉴收集的目标。

## 6.3 非遗制作规则

| 规则 | 说明 |
| --- | --- |
| 制作地点 | 工坊 |
| 身份限制 | 无，所有玩家可制作所有35省非遗 |
| 材料消耗 | 所有玩家一致，无减免 |
| 制作时间 | 由配置表决定，不可加速（V0.1.0-alpha） |
| 取消 | 可取消，返还50%材料 |
| 完成 | 产物进背包，可放展示柜或用于派遣 |
| 展示柜 | 放入后+1格展示，纯展示无额外效果 |

## 6.4 非遗制作步骤（Lua驱动示例）

```lua
-- 美浓油纸伞的制作步骤定义
NF_美浓油纸伞 = {
    provinceId = 34,
    name = "美浓油纸伞",
    totalTime = 240, -- 4小时（分钟）
    intimacy = 35,
    difficulty = 4,
    materials = {
        {itemId = "竹片", count = 4},
        {itemId = "构树皮纸", count = 3},
        {itemId = "桐油", count = 2}
    },
    steps = {
        {name = "劈竹", time = 30, anim = "craft_hammer", desc = "将竹子劈成细条做伞骨"},
        {name = "制伞骨", time = 60, anim = "craft_assemble", desc = "将竹条组装成伞骨结构"},
        {name = "糊纸", time = 60, anim = "craft_paint", desc = "在伞骨上糊上构树皮纸"},
        {name = "刷桐油", time = 90, anim = "craft_brush", desc = "反复刷上桐油防水"}
    }
}
```
