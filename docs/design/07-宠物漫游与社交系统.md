# 文档七：宠物漫游与社交系统

> 版本：V0.1.0-alpha

## 7.1 宠物属性表

| 属性 | 说明 | 初始值 | 上限 |
| --- | --- | --- | --- |
| 等级 | 决定单次派遣访问数量 | 1 | 20 |
| 经验值 | 升级所需 | 0 | 按等级曲线 |
| 好感度 | 影响派遣成功率 | 0 | 100 |
| 状态 | 在家/派遣中/休息中 | 在家 | - |
| 外观 | 皮肤/装饰 | 默认 | 可更换 |

## 7.2 宠物等级与访问数量

| 等级 | 访问庭院数 | 经验需求 | 升级方式 |
| --- | --- | --- | --- |
| 1 | 2 | 0 | 初始 |
| 2 | 2 | 20 | 喂食/派遣归来 |
| 3 | 3 | 50 | 喂食/派遣归来 |
| 5 | 3 | 150 | 喂食/派遣归来 |
| 10 | 4 | 800 | 喂食/派遣归来 |
| 15 | 5 | 2500 | 喂食/派遣归来 |
| 20（满） | 5 | 6000 | 喂食/派遣归来 |

公式：访问数 = floor(等级/5) + 2，上限5

## 7.3 宠物经验获取途径

| 途径 | 经验值 | 说明 |
| --- | --- | --- |
| 派遣归来（每次） | 10 | 基础经验 |
| 成功留下信+非遗 | +5/次 | 有食物时才获得 |
| 被喂食（好友） | +2/次 | 上限+10/天 |
| 每日任务 | 5~20 | 视任务难度 |
| 喂食（自己喂） | +1/次 | 上限+5/天 |

## 7.4 宠物状态流转

```
在家（可互动/可派遣）
    │
    │ 点击"派遣"→选择目的地→确认
    ▼
派遣中（不可互动，显示"外出中"）
    │
    │ 8小时后自动触发
    ▼
休息中（不可派遣，显示"疲惫中"）
    │
    │ 休息8小时后自动触发
    ▼
在家
```

## 7.5 派遣流程详细步骤

| 步骤 | 界面 | 交互 | 校验 |
| --- | --- | --- | --- |
| 1 | 点击宠物 | 弹出宠物面板 | 状态必须为"在家" |
| 2 | 点击"派遣" | 弹出手绘地图 | - |
| 3 | 选择省份 | 点击地图省份→弹出城市列表 | 不可选本省 |
| 4 | 选择城市 | 点击城市或"随机" | 可选，不选则随机 |
| 5 | 返回派遣面板 | 确认目的地显示 | - |
| 6 | 选择非遗 | 从背包选择1个非遗 | 必须有≥1个非遗 |
| 7 | 检查口粮 | 自动检查背包 | 必须有≥1份口粮（路上吃） |
| 8 | 写信 | 手写/模板/快捷短语 | 50字限制 |
| 9 | 确认派遣 | 点击"出发" | 全部条件满足才可点击 |
| 10 | 宠物出发 | 播放派遣动画 | 状态变"派遣中" |

## 7.6 访问触发链（核心逻辑）

```
宠物到达目标庭院
    │
    ▼
Step 1：检查对方食物盆是否有食物
    │
    ├──【无食物】
    │  ① 不留下任何东西
    │  ② 对方收到通知："有只来自[省份]的[宠物名]来过，但你没准备吃的，它饿着肚子走了😢"
    │  ③ 宠物获得1枚该省徽章
    │  ④ 宠物消耗1份自身背包口粮（路上吃）
    │  ⑤ 进入下一个庭院（如果有）
    │
    └──【有食物】
        ① 宠物吃掉对方食物盆里的1份口粮
        ② 宠物消耗1份自身背包口粮（路上吃）
        ③ 留下1封信（存入对方信箱）
        ④ 留下1个非遗（存入对方信箱）
        ⑤ 对方收到通知："有只来自[省份]的[宠物名]留下了信件和[非遗名]🎁"
        ⑥ 宠物获得1枚该省徽章
        ⑦ 进入下一个庭院（如果有）
```

## 7.7 匹配算法（Lua实现）

```lua
function MatchMaker.FindTargets(provinceId, cityId, count, hospitalityValues)
    -- provinceId: 目标省份
    -- cityId: 目标城市（nil则不限城市）
    -- count: 需要匹配的庭院数量
    -- hospitalityValues: 该省份的好客值Sorted Set

    local candidates = {}

    if cityId then
        -- 指定城市：先从该城市的好客值池取
        candidates = Redis.ZRevRange("match_pool:"..provinceId..":"..cityId, 0, count*3)
    end

    -- 城市不够或从省池补充
    if #candidates < count then
        local provinceCands = Redis.ZRevRange("match_pool:"..provinceId, 0, count*3)
        for _, c in ipairs(provinceCands) do
            if not in_list(candidates, c) then
                table.insert(candidates, c)
            end
        end
    end

    -- 过滤不可用（离线/食物盆空/被屏蔽）
    local targets = {}
    for i, userId in ipairs(candidates) do
        if CheckUserAvailable(userId) then
            table.insert(targets, userId)
            if #targets >= count then break end
        end
    end

    -- 不足时填充NPC庭院
    while #targets < count do
        table.insert(targets, GetNPCCourtyard(provinceId))
    end

    return targets
end
```

## 7.8 匹配权重说明

| 权重因素 | 说明 | 占比 |
| --- | --- | --- |
| 好客值 | 主要排序依据 | 60% |
| 随机扰动 | 防止马太效应 | 20% |
| 首次访问优先 | 未访问过的庭院优先 | 10% |
| 好友权重 | 好友庭院权重略高 | 10% |

## 7.9 归家结算

| 内容 | 说明 |
| --- | --- |
| 状态变化 | 派遣中→休息中（8小时冷却） |
| 明信片报告 | 手绘明信片，显示去了哪几个城市、吃了什么、留下了什么 |
| 信箱收信 | 对方回赠的信件+非遗（次日08:00结算送达） |
| 徽章获取 | 每访问一省获得1枚徽章 |
| 经验获取 | 基础10 + 成功留下信每封+5 |
| 宠物升级 | 经验满后升级，访问数量+1 |

## 7.10 信件系统详细规则

**写信**

| 方式 | 说明 | 限制 |
| --- | --- | --- |
| 手写 | 虚拟键盘输入 | 50字 |
| 模板 | Lua配置的模板库 | 选择1个 |
| 快捷短语 | 常用语快捷选择 | 点击即用 |

**信件模板示例**

| ID | 模板内容 | 风格 |
| --- | --- | --- |
| T01 | "你好呀！我是来自[省份]的[宠物名]，这是我家乡的[非遗名]，希望你喜欢～" | 友好 |
| T02 | "听说你们那里[特产]很有名，下次能带点给我吗？😊" | 好奇 |
| T03 | "你的院子真好看！特别是那棵[装饰名]，太有品味了！" | 赞美 |
| T04 | "长途跋涉来到这里，肚子好饿呀，希望能吃到好吃的～" | 可爱 |
| T05 | "这是我精心制作的[非遗名]，花了很久呢，请好好珍惜它～" | 认真 |

**收信操作**

| 操作 | 说明 |
| --- | --- |
| 打开信箱 | 显示信件列表（手绘信封图标+未读红点） |
| 阅读信件 | 信笺展开+圆体可爱字迹逐字显现动画 |
| 查看附赠非遗 | 点击信件中的非遗图标→弹出详情 |
| 加为好友 | 点击"加好友"→发送申请 |
| 回赠 | 点击"回赠"→选择背包中的非遗+写信→寄出 |
| 忽略 | 点击"忽略"→信件保留但无操作 |

**信件审核**

| 层级 | 方式 | 说明 |
| --- | --- | --- |
| 第一层 | 阿里云AI内容安全 | 自动过滤违规内容 |
| 第二层 | 人工审核后台 | AI不确定的转人工 |
| 第三层 | 玩家举报 | 收到后可举报 |
| 豁免 | 好友间互发 | 免审，即时送达 |

**信件状态流转**

```
撰写中 → 待审核 → 审核通过 → 已送达（对方信箱）
                  → 审核不通过 → 退回+通知
```
