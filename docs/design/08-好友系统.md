# 文档八：好友系统

> 版本：V0.1.0-alpha

## 8.1 加好友流程

| 步骤 | 说明 |
| --- | --- |
| 触发 | 收到回信后信件底部显示"加为好友"按钮 |
| 申请 | 点击→发送好友申请（含附带消息，可选） |
| 通知 | 对方下次上线收到申请通知 |
| 同意 | 点击"同意"→建立双向好友关系 |
| 拒绝 | 点击"拒绝"→申请作废 |

## 8.2 好友互动一览

| 互动 | 说明 | 每日限制 | 奖励 | 通知 |
| --- | --- | --- | --- | --- |
| 私聊 | 文字消息 | 无 | - | - |
| 互访庭院 | 查看好友庭院布局 | 无 | - | - |
| 偷菜 | 收获好友成熟作物的30% | 每株作物1次/天，总20次/天 | 获得30%产量 | 对方收到通知 |
| 喂食 | 喂好友在家的宠物 | 每只3次/天 | 无 | 对方收到通知 |
| 查看图鉴 | 查看好友收集进度 | 无 | - | - |
| 快速回赠 | 回赠免审核 | 无 | - | - |
| 赠送礼物 | 赠送材料/种子 | 1次/天/人 | 对方获得物品 | 对方收到通知 |

## 8.3 偷菜机制详细规则

| 规则 | 说明 |
| --- | --- |
| 触发 | 访问好友庭院→点击成熟作物 |
| 判定 | 作物必须处于"成熟"状态（非生长中） |
| 数量 | 获得该作物产量的30%（向下取整） |
| 剩余 | 好友农田剩余70% |
| 限制 | 同一好友同一作物每天只能偷1次 |
| 总限 | 每天最多偷20次（跨所有好友累计） |
| 保护 | 保护罩道具（邮券购买）24小时免疫被偷 |
| 通知 | 好友收到"[名字]偷走了你的X！" |
| 关系 | 好友间不算恶意行为 |

## 8.4 喂食机制详细规则

| 规则 | 说明 |
| --- | --- |
| 触发 | 访问好友庭院→点击好友的宠物（必须"在家"状态） |
| 选择 | 从自己背包选1份口粮 |
| 消耗 | 自己背包扣除1份口粮 |
| 动画 | 播放喂食动画（宠物吃+开心表情+爱心粒子） |
| 限制 | 同一好友同一宠物每天最多喂3次 |
| 通知 | 好友收到"[名字]喂了你的[宠物名]！" |

## 8.5 好友加成

| 加成 | 数值 | 说明 |
| --- | --- | --- |
| 好客值 | +50 | 有≥1个好友即生效 |
| 匹配权重 | +10% | 好友互访概率略高 |
| 回赠审核 | 免审 | 好友间即时送达 |
| 偷菜关系 | 无惩罚 | 好友间偷菜正常互动 |

| 庭院2级 | 30 |
| 庭院3级 | 50 |
| 庭院4级 | 100 |
