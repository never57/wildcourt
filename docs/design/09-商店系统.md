# 文档九：商店系统

> 版本：V0.1.0-alpha

## 9.1 货币体系

| 货币 | 来源 | 用途 | 是否可充值 |
| --- | --- | --- | --- |
| 庭贝 | 售卖原始作物/每日签到/活动/小游戏 | 购买种子/材料/装饰/道具 | 否（仅游戏内获取） |
| 邮券 | 仅活动获取（节日/限时/运营活动奖励） | 跳过各类CD（建筑升级/加工/作物生长）、购买商店内部分限定物品 | 否（不可购买、不可交易、不可兑换庭贝） |

V0.1.0-alpha主要有两种货币：庭贝（日常软货币）与邮券（活动限定货币）。

### 9.1.1 邮券（活动限定货币）

- **获取**：唯一来源为活动奖励（节日活动/限时活动/运营活动/连续登录等）；不参与日常产出，不可用庭贝购买，不可玩家间交易，不可逆向兑换庭贝。
- **用途**：
  1. **跳过冷却（CD）**：消耗邮券立即完成进行中的 CD，包括：
     - 庭院建筑升级 CD（文档三 3.4）
     - 加工物品 CD（文档四 4.9）
     - 作物生长 CD（通过施加化肥完成，化肥于商店用邮券购买，详见 9.7）
  2. **商店购买**：商店内部分物品可用邮券购买（如限定装饰、特殊种子、宠物道具、化肥等）；普通日常物品仍用庭贝。化肥为邮券商店专属道具，1邮券可购多份（详见 9.7）。
- **规则**：
  - 不可通过庭贝兑换，不可逆向（邮券→庭贝）。
  - 活动结束后未使用的邮券不清零，长期保留。

## 9.8 商店UI规范

| 元素 | 规范 |
| --- | --- |
| 入口 | 主界面"商店"按钮→进入商店场景 |
| 货架Tab | 顶部横向：种子/材料/装饰/道具 |
| 装饰子分类 | 左侧纵向：全部/景观/建筑小品/家具/容器/宠物/地面/节日 |
| 商品卡片 | 手绘图标+名称+价格+购买按钮 |
| 已拥有 | 灰色遮罩+数量角标 |
| 未拥有 | 正常显示+价格+购买按钮 |
| 购买确认 | 点击购买→弹出确认框"确认花费X庭贝购买？"（邮券道具显示"确认花费X邮券购买？"）→确认→扣对应货币→物品进背包 |
| 庭贝不足 | 红色提示"庭贝不足"+引导去卖作物/签到/活动/小游戏 |
| 邮券不足 | 红色提示"邮券不足"+引导去参与活动获取邮券（邮券仅活动产出，详见文档十三 12.5） |
