# 文档九：商店系统

> 版本：V0.1.0-alpha

## 9.1 货币体系

| 货币 | 来源 | 用途 | 是否可充值 |
| --- | --- | --- | --- |
| 庭贝 | 售卖农产品/每日签到/活动/小游戏 | 购买种子/材料/装饰/道具 | 否（仅游戏内获取） |

V0.1.0-alpha仅一种货币，不设计充值系统。后续版本可考虑添加"钻石"作为付费货币。

## 9.8 商店UI规范

| 元素 | 规范 |
| --- | --- |
| 入口 | 主界面"商店"按钮→进入商店场景 |
| 货架Tab | 顶部横向：种子/材料/装饰/道具 |
| 装饰子分类 | 左侧纵向：全部/景观/建筑小品/家具/容器/宠物/地面/节日 |
| 商品卡片 | 手绘图标+名称+价格+购买按钮 |
| 已拥有 | 灰色遮罩+数量角标 |
| 未拥有 | 正常显示+价格+购买按钮 |
| 购买确认 | 点击购买→弹出确认框"确认花费X庭贝购买？"→确认→扣庭贝→物品进背包 |
| 庭贝不足 | 红色提示"庭贝不足"+引导去卖农产品/签到/活动/小游戏 |
