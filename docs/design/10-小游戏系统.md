# 文档十：小游戏系统

> 版本：V0.1.0-alpha

## 18.1 系统定位

小游戏是一组**轻量、即时反馈**的休闲玩法，作为庭贝的获取来源之一（文档九 9.2：小游戏 10~50 庭贝/局）。与核心的异步生产 / 社交玩法互补，给玩家提供"随时来一局、马上得奖励"的短平快体验，不承担数值养成职责。

设计原则（红线延伸）：

- 小游戏产出**仅庭贝 + 少量趣味道具**，不产出可交易的核心材料（避免冲击经济）。
- 设**每日获取上限**控制通胀（与文档一 1.11 红线一致）。
- 玩法松耦合，新增玩法走 Lua 配置热更（文档十四），不依赖发版。
- 美术统一 Q版可爱风（圆角、圆体可爱字、柔和水彩）。

## 18.2 小游戏清单（V0.1.0-alpha）

| 小游戏 | 类型 | 玩法简述 | 单局时长 |
| --- | --- | --- | --- |
| 拼图 | 拼图 | 把被打乱的省份/非遗 Q版插画拼回完整 | 30~90s |
| 找茬 | 找不同 | 两幅 Q版庭院图找出 N 处差异 | 30~60s |
| 记忆翻牌 | 翻牌 | 翻牌配对省花/宠物，配对成功得分 | 40~80s |
| 接信 | 反应 | 控制宠物接住从天而降的信封，漏接扣分 | 30~45s |
| 节奏点击 | 音游 | 跟随 BGM 节拍点击音符，连击加成 | 30~60s |

> 钓鱼为庭院生产玩法（文档四），不计入此处小游戏；如需以休闲入口复用钓鱼，可后续在 `Config_MiniGame` 挂接同源逻辑。

## 18.3 单局流程

```
主界面"小游戏"入口
    ↓
选择小游戏（圆角卡片列表）
    ↓
开始 → 加载 Lua 配置与美术资源
    ↓
游玩（即时反馈：得分/连击/计时）
    ↓
结算 → 评级 S/A/B/C
    ↓
发放庭贝（按评级）
    ↓
记入 transactions（type=minigame）→ 返回入口
```

## 18.4 庭贝获取规则

| 评级 | 庭贝 | 触发条件 |
| --- | --- | --- |
| S | 50 | 满分 / 全配对 / 零漏接 |
| A | 35 | 高分 |
| B | 20 | 通过 |
| C | 10 | 勉强通过 |

- 单局庭贝 10~50，与文档九 9.2 口径一致。
- 评级由各玩法分数映射，映射表写在 `Config_MiniGame`。

## 18.5 每日获取上限（控通胀）

| 来源 | 每日庭贝上限（建议） | 说明 |
| --- | --- | --- |
| 小游戏 | 200 | 约 4~5 局满额（S 评级）后封顶 |
| 签到 | 30 | 见文档十一 |

超出上限后当日小游戏仍可进行，但不再发放庭贝（提示"今日小游戏庭贝已领完"）。上限数值由数值配置表（文档十六）维护，可随版本调整。

## 18.6 小游戏 UI 规范（Q版可爱风）

| 元素 | 规范 |
| --- | --- |
| 入口 | 主界面"小游戏"按钮 → 圆角卡片列表 |
| 卡片 | 手绘图标 + 名称 + 预计时长 + 最佳评级 |
| 结算弹窗 | 圆角糖果色，显示评级徽章 + 庭贝飘入动画 |
| 失败/退出 | 不惩罚，可直接重开 |
| 音效 | 可爱轻音效，可静音 |

## 18.7 配置（Lua 驱动）

```lua
-- Config_MiniGame.lua
MiniGame_List = {
    {id = "puzzle",      name = "拼图",   type = "puzzle",   reward = {S=50,A=35,B=20,C=10}},
    {id = "spot",        name = "找茬",   type = "spot",     reward = {S=50,A=35,B=20,C=10}},
    {id = "memory",      name = "记忆翻牌", type = "memory",  reward = {S=50,A=35,B=20,C=10}},
    {id = "catch",       name = "接信",   type = "catch",    reward = {S=50,A=35,B=20,C=10}},
    {id = "rhythm",      name = "节奏点击", type = "rhythm",  reward = {S=50,A=35,B=20,C=10}},
}

MiniGame_DailyCap = 200   -- 每日庭贝上限（控通胀）
```

## 18.8 与服务端的关系

| 职责 | 归属 |
| --- | --- |
| 玩法逻辑 | 客户端 `MiniGame/` + Lua（`StreamingAssets/lua/Logic/MiniGame/`） |
| 庭贝发放 | `MiniGameService` 校验每日上限后发放，记入 `transactions`（type=minigame） |
| 每日上限 | 服务端校验，本地缓存仅作展示 |
| 防作弊 | 服务端二次校验单局分数与评级，拒绝异常高分 |
