# 文档十一：每日签到系统

> 版本：V0.1.0-alpha

## 17.1 系统定位

签到是**每日循环**的一部分，不是独立入口型玩法。玩家每天首次登录即视为签到，由每日结算任务（`DailySettlementJob`，每日 08:00 服务器时间触发，见文档十四 11.5 第 8 项"连续登录奖励"）统一结算连续登录天数与奖励。

设计目标：

- 提供稳定、低门槛的庭贝来源（文档九 9.2：每日签到 5~30 庭贝/天）。
- 通过"连续递增 + 断签重置"培养每日留存习惯。
- 与每日任务、活动奖励互补，构成新手与轻度玩家的主要庭贝入口。

## 17.2 签到规则

| 规则 | 说明 |
| --- | --- |
| 触发时机 | 每日首次登录自动签到；也可在主界面"每日"面板手动补点 |
| 连续递增 | 连续登录天数 +1，当日庭贝随天数递增（5→30） |
| 断签重置 | 跨天未登录（连续登录中断）→ 连续天数清零回 1 |
| 周期 | 7 天为一轮，第 7 天额外大奖；轮次循环不累计 |
| 补签 | 不做付费补签（V0.1.0-alpha）；仅自然断签后从 Day1 重新累计 |
| 时区 | 统一使用服务器时区（UTC+8），与每日结算一致 |

## 17.3 签到奖励表（7 天一轮）

| 天数 | 庭贝 | 额外奖励 | 说明 |
| --- | --- | --- | --- |
| Day1 | 5 | - | 基础签到 |
| Day2 | 8 | - | - |
| Day3 | 10 | 小麦种子×1 | 轻微引导自种 |
| Day4 | 12 | - | - |
| Day5 | 15 | 邮券×1 | 轻量道具 |
| Day6 | 20 | 宠物口粮×2 | - |
| Day7 | 30 | 限定装饰（周签专属）×1 | 轮次大奖，循环重置 |

> 庭贝数值为 V0.1.0-alpha 建议值，最终以数值配置表（文档十六）为准。

## 17.4 累计签到（月签）

| 累计天数 | 奖励 |
| --- | --- |
| 累计 14 天 | 庭贝×100 |
| 累计 30 天 | 限定装饰×1 + 庭贝×200 |

累计天数跨月不清零，仅记录自然月内累计；断签不影响"累计"统计（与"连续"区分）。

## 17.6 配置（Lua 驱动）

签到配置由 Lua 表驱动，可随版本热更（见文档十四 11.1），无需发新包。

```lua
-- Config_DailySignIn.lua
DailySignIn_Week = {
    cycle = 7,
    rewards = {
        {day = 1, shell = 5},
        {day = 2, shell = 8},
        {day = 3, shell = 10, item = "seed_wheat", count = 1},
        {day = 4, shell = 12},
        {day = 5, shell = 15, item = "coupon_speed", count = 1},
        {day = 6, shell = 20, item = "pet_food", count = 2},
        {day = 7, shell = 30, item = "deco_week", count = 1},
    }
}

DailySignIn_Month = {
    milestones = {
        {total = 14, shell = 100},
        {total = 30, shell = 200, item = "deco_month", count = 1},
    }
}
```

## 17.7 与服务端的关系

| 职责 | 归属 |
| --- | --- |
| 连续登录天数统计 | `SettlementService`（每日结算，文档十四） |
| 签到奖励发放 | 结算任务内联发放，记入 `transactions` 表（`type=sign_in`） |
| 签到状态查询 | 客户端读取本地缓存 + 服务端 `SignIn` 字段 |
| 防作弊 | 服务端校验每日仅可签到 1 次，重复请求拒绝 |

> 为避免逻辑重复，V0.1.0-alpha 不单独拆分 `DailySignInService`，签到结算复用每日结算链路；仅在客户端新增 `SignInManager` 负责 UI 与本地状态。
