# 文档十一：热更新与每日结算系统

> 版本：V0.1.0-alpha

## 11.1 可热更内容清单

| 类型 | 说明 | 存放目录 |
| --- | --- | --- |
| 配置表 | Excel导出的Lua表 | StreamingAssets/config/ |
| Lua逻辑 | 玩法逻辑/活动脚本 | StreamingAssets/lua/ |
| UI脚本 | UI绑定逻辑 | StreamingAssets/lua/UI/ |
| 活动配置 | 节日活动/限时活动 | StreamingAssets/lua/Logic/Activity/ |
| 美术资源 | Sprite/Spine/UI图集 | StreamingAssets/[sprite spine ui]/ |

## 11.2 不可热更内容

| 类型 | 说明 | 更新方式 |
| --- | --- | --- |
| C#核心代码 | 需重新编译 | 重新发包（APK/IPA） |
| 引擎修改 | Unity版本升级 | 重新发包 |
| 新增原生插件 | 如新SDK接入 | 重新发包 |

## 11.3 热更流程

```
启动游戏
    ↓
请求服务端 version.txt
    ↓
对比本地版本号
    ↓
本地 < 服务端？
    ├── 否 → 正常进入游戏
    └── 是 → 下载 manifest.json
              ↓
          对比每个文件的 MD5
              ↓
          有差异？
              ├── 否 → 正常进入游戏
              └── 是 → 下载差异文件 → 存入 persistentDataPath
                        ↓
                   加载新资源 → LuaManager.HotReload()
                        ↓
                   配置表重新读取 → 完成更新 → 进入游戏
```

## 11.4 热更失败处理

| 失败场景 | 处理方式 |
| --- | --- |
| 下载中断 | 记录进度，下次启动续传 |
| MD5校验失败 | 删除该文件，重新下载 |
| Lua加载报错 | 自动回滚到上一版本Lua |
| 资源加载失败 | 使用本地缓存的旧资源 |
| 连续失败3次 | 提示玩家"更新失败，请检查网络"，跳过热更进入游戏 |

## 11.5 每日结算详细规则

**结算时间**

每天 08:00:00 服务器时间，由Quartz定时任务触发。

**结算内容清单**

| 序号 | 内容 | 说明 |
| --- | --- | --- |
| 1 | 作物成熟判定 | 成熟超2小时未收→标记枯萎 |
| 2 | 食物变质判定 | 食物盆中食物超24小时→标记变质 |
| 3 | 宠物状态恢复 | 休息满8小时→状态变"在家" |
| 4 | 信件回赠结算 | 昨日对方寄出的回赠→送达收件人信箱 |
| 5 | 好客值衰减 | 连续未招待-10/天，空盆-50，7日未登录-100 |
| 6 | 连续招待天数 | 昨日有招待+1，无招待清零 |
| 7 | 每日任务刷新 | 清空旧任务，生成新任务 |
| 8 | 登录奖励发放 | 连续登录天数+1，发放对应奖励 |
| 9 | 排行榜更新 | 好客值排行榜重新排序 |
| 10 | 活动状态检查 | 检查活动开始/结束条件 |

**结算通知**

每日08:00推送：

"早安！你的院子里有[数量]个作物成熟了，食物盆还剩[数量]份食物，[宠物名]已经休息好了在家等你～"

**结算失败处理**

| 场景 | 处理 |
| --- | --- |
| 服务器宕机 | 恢复后补跑结算，补偿玩家损失 |
| 个别玩家结算失败 | 记录日志，下次登录时手动补算 |
| 时区问题 | 统一使用服务器时区（UTC+8） |
