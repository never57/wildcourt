# 文档十三：活动系统

> 版本：V0.1.0-alpha

## 12.1 节日活动一览

| 节日 | 时间（农历/公历） | 活动内容 | 奖励 |
| --- | --- | --- | --- |
| 春节 | 农历正月初一前后2周 | 限定装饰（灯笼/春联/窗花）+限定非遗（剪纸） | 限定装饰+限定徽章 |
| 元宵 | 农历正月十五 | 猜灯谜活动（答题得材料） | 稀有材料 |
| 清明 | 公历4月5日前后1周 | 踏青活动（限定鱼饵，咬钩概率与稀有鱼权重提升） | 稀有鱼类 |
| 端午 | 农历五月初五 | 包粽子限定食谱（糯米+竹叶） | 限定口粮 |
| 中秋 | 农历八月十五 | 赏月活动+限定装饰（月亮/玉兔） | 限定装饰+限定徽章 |
| 国庆 | 公历10月1日 | 全国巡礼活动（访问所有省得称号） | 限定称号"山河旅人" |
| 圣诞 | 公历12月25日 | 限定装饰（圣诞树/雪花） | 限定装饰 |

## 12.2 限时活动

| 活动 | 内容 | 触发条件 |
| --- | --- | --- |
| 新版本上线 | 新增省份非遗+配套装饰 | 版本更新 |
| 好友邀请 | 老玩家邀新玩家→双方得奖励 | 分享链接注册 |
| 庭院摄影大赛 | 玩家上传截图→投票→获奖 | 运营活动（季度） |
| 非遗知识问答 | 每日答对得材料/庭贝 | 每日1次 |
| 连续登录 | 连续7天登录→限定装饰 | 自动触发 |

## 12.3 活动配置（Lua驱动）

```lua
-- 中秋活动示例
Activity_MidAutumn = {
    id = "midautumn_2026",
    name = "月圆人团圆",
    startTime = "2026-09-25 00:00:00",
    endTime = "2026-10-05 23:59:59",
    type = "festival",
    content = {
        {type = "decoration", itemId = "D_moon", name = "中秋圆月", price = 300},
        {type = "decoration", itemId = "D_rabbit", name = "玉兔雕塑", price = 250},
        {type = "badge", itemId = "B_midautumn", name = "中秋徽章"},
        {type = "task", desc = "在中秋期间访问5个不同省份的庭院", reward = "月饼食谱"}
    }
}
```

## 12.4 活动上线流程

| 步骤 | 说明 |
| --- | --- |
| 1.策划配置 | 在Lua中写好活动配置 |
| 2.美术资源 | 制作活动专属装饰/徽章素材 |
| 3.热更推送 | 通过热更系统推送，无需发新包 |
| 4.服务端激活 | 到达开始时间自动激活 |
| 5.结束处理 | 到达结束时间自动关闭，发放未领奖励 |

## 12.5 邮券产出

邮券为**活动限定货币**，是游戏中获取邮券的**唯一途径**——仅通过本系统发放的奖励（12.1 节日活动、12.2 限时活动）产出，不参与任何日常玩法。其具体用途与规则详见文档九 9.1.1。
