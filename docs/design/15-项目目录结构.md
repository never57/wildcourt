# 文档十五：项目目录结构

> 版本：V0.1.0-alpha

## 13.1 客户端目录（Unity 2022.3.62f3c1）

```
client/
├── Assets/
│   ├── Art/                   # 美术资源（UI/Sprite/Spine/Fonts，细分见各系统文档）
│   ├── Prefabs/               # 预制体（UI/Effects）
│   ├── Resources/             # Resources（Config/Templates）
│   ├── Scenes/                # 场景（Launch/ProvinceSelect/Main/Yard…）
│   ├── Scripts/               # 脚本（Core/UI/Gameplay/Net/Utils/Lua）
│   │   └── PlayerLevel.cs      # 玩家经验/等级管理（读取 Config_PlayerLevel）
│   ├── LuaScripts/            # Lua 脚本（Config/Logic/UI/Localization）
│   │   ├── Config/
│   │   │   └── Config_PlayerLevel.lua  # 玩家等级曲线（文档十六 Sheet17）
│   ├── Plugins/               # 插件（XLua/Firebase 等三方包）
│   └── StreamingAssets/
│       └── version.txt        # 应用版本号 V0.1.0-alpha
├── Packages/
│   ├── manifest.json          # 包清单（Unity 2022.3.62f3c1 基础包）
│   └── packages-lock.json     # 包锁定（Unity 生成）
├── ProjectSettings/           # Unity 工程设置（由 Unity 管理）
│   └── ProjectVersion.txt     # m_EditorVersion: 2022.3.62f3c1
├── .gitignore                 # 忽略 Library/Logs/UserSettings 等生成目录
├── Library/                   # ⚠️ Unity 生成，已 gitignore，不入库
├── Logs/                      # ⚠️ Unity 生成，已 gitignore，不入库
└── UserSettings/              # ⚠️ Unity 生成，已 gitignore，不入库
```

> 说明：当前 `Assets/` 仅建立一级分类目录，子目录的细分（如 `Art/UI`、`Scripts/Gameplay`、`LuaScripts/Config` 等）见各系统文档的设计约定，开发过程中按设计逐步填充。`ProjectSettings/` 下其余 `.asset` 文件（GraphicsSettings/InputManager/Physics2DSettings/QualitySettings 等）由 Unity 在首次打开工程时自动生成并管理，此处不再逐一列举。`Library/`、`Logs/`、`UserSettings/` 为本地生成目录，已在 `.gitignore` 忽略，不纳入版本管理。

## 13.3 数据库表结构

**MySQL表清单**

| 表名 | 说明 | 核心字段 |
| --- | --- | --- |
| users | 用户表 | user_id, nickname, province_id, city_id, level, created_at, last_login |
| pets | 宠物表 | pet_id, user_id, type, level, exp, status |
| inventories | 背包表 | user_id, item_id, count |
| yards | 庭院表 | user_id, layout_json, level, updated_at |
| letters | 信件表 | letter_id, from_user, to_user, content, item_id, status, created_at |
| friends | 好友关系表 | user_id, friend_id, created_at |
| nonfiction_collections | 图鉴收集表 | user_id, province_id, unlocked_at |
| badges | 徽章表 | user_id, province_id, count, first_obtained |
| transactions | 交易记录表 | trans_id, user_id, type, item_id, count, price |
| match_pools | 匹配池缓存表 | province_id, user_id, hospitality_score |
| operation_logs | 操作日志表 | log_id, user_id, action, details, created_at |
| daily_settlements | 每日结算队列 | user_id, settle_date, status |
| sign_in_records | 签到记录表 | user_id, sign_date, cycle_day, reward_shell |

**Redis Key清单**

| Key | 类型 | 说明 |
| --- | --- | --- |
| online_status:{userId} | String | 在线状态 |
| hospitality_values:{provinceId} | Sorted Set | 好客值排名 |
| match_pool:{provinceId} | Sorted Set | 匹配池 |
| match_pool:{provinceId}:{cityId} | Sorted Set | 城市级匹配池 |
| daily_settlement_queue | List | 每日结算队列 |
| letter_audit_queue | List | 信件审核队列 |
| yard_layout:{userId} | String | 庭院布局缓存 |
| user_session:{token} | String | 用户会话 |
