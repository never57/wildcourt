# 文档十六：数值配置表规范

> 版本：V0.1.0-alpha

## 16.1 配置表总览

共17张Excel表，每张表对应一个JSON配置文件（命名 `Config_*.json`），由Python脚本自动转换。客户端（ConfigMgr）与服务端（.NET）同读同一份 JSON，保证数值一致。

## 16.2 各表字段定义

**Sheet1: Provinces**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 省份ID（1~34） |
| name | string | 省份名称 |
| region | string | 所属大区（华北/东北/华东等） |
| mapColor | string | 地图显示色（十六进制） |

**Sheet2: Cities**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 城市ID |
| name | string | 城市名称 |
| provinceId | int | 所属省份ID |
| pinyin | string | 拼音（用于排序和搜索） |

**Sheet3: Crops**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 作物ID |
| name | string | 作物名称 |
| growTime | int | 生长时间（分钟） |
| yield | int | 产量 |
| sellPrice | int | 售价 |
| processTo | string | 加工产物ID（无则为空） |
| processTime | int | 加工时间（分钟） |

**Sheet4: Fish**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 鱼类ID |
| name | string | 名称 |
| rarity | string | 普通/稀有 |
| sellPrice | int | 售价 |
| note | string | 出现概率由鱼饵出鱼权重决定（见 Sheet4.1 Bait），本表不存概率 |

**Sheet4.1: Bait**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 鱼饵ID（B01/B02/B03 + 活动限定） |

| price | int | 售价（庭贝） |
| durationSec | int | 生效时长（秒），固定 60 |
| hookRate | int | 咬钩概率（百分比） |

**Sheet5: ProcessRecipes**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 配方ID |
| inputItem | string | 输入物品 |

| outputItem | string | 输出物品 |
| outputCount | int | 输出数量 |
| time | int | 加工时间（分钟） |

**Sheet6: FoodRecipes**

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 食谱ID |

| mat1Cnt | int | 材料1数量 |
| mat2 | string | 材料2（可空） |

**Sheet7: Nonfictions**

| 列名 | 类型 | 说明 |
| --- | --- | --- |

| name | string | 名称 |

| template | string | 互动素材与提示配置（JSON，含 mode/parts/hint 等，见文档六 6.4.3 示例） |

**Sheet8: HospitalityWeights**

## 16.3 导出流程

```
Excel填写（策划）
    ↓
Python脚本（Excel2JSON.py）
    ↓
校验（字段类型/必填项/引用完整性）
    ↓
输出JSON文件到 StreamingAssets/config/（命名 Config_*.json）
    ↓
客户端启动时 ConfigMgr 加载（只读），热更由 manifest.json MD5 对比增量拉取
    ↓
服务端同步部署同一份 JSON 配置（.NET 读取，数值一致）
```
