## 15.4 新人入职配置步骤

```
1. Clone客户端仓库 → Unity 2022.3.62f3c1打开client/
2. Clone服务端仓库 → VS2022打开server/
3. 客户端：确保StreamingAssets/version.txt存在
4. 客户端：运行Excel2Lua.py转换配置表
5. 服务端：执行init_db.sql初始化数据库
6. 服务端：修改appsettings.Development.json连接串
7. 服务端：dotnet run启动
8. 联调：客户端GameManager设服务端地址为localhost:5000
```
