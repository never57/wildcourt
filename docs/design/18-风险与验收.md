# 文档十八：风险与验收

> 版本：V0.1.0-alpha

## 16.1 风险清单

| 风险 | 可能性 | 影响 | 应对措施 |
| --- | --- | --- | --- |
| 信件审核漏洞 | 中 | 高 | AI+人工+举报三重保障 |
| 服务器宕机 | 低 | 高 | 负载均衡+自动重启+每日备份 |
| 刷庭贝漏洞 | 中 | 中 | 服务端校验+操作日志监控 |
| 偷菜引发纠纷 | 高 | 低 | 设定为"邻里互助"+保护罩道具 |
| 内容枯竭 | 中 | 中 | 活动系统+季节限定持续更新 |
| 竞品冲击 | 低 | 高 | 非遗文化壁垒+地域归属感难复制 |
| 美术产能不足 | 中 | 中 | 简化装饰物数量+外包 |
| 台湾标注争议 | 低 | 极高 | 明确标注"中国第34个省级行政区"，内部审核把关 |

## 16.2 技术验收标准

| 项目 | 验收标准 |
| --- | --- |
| 庭院建造 | 50~200个装饰物自由摆放，渲染正确，保存/加载无误 |
| 生产链 | 种植→加工→制作→派遣全流程无卡顿 |
| 社交 | 派遣→匹配→访问→回赠→加好友→互访完整链路通畅 |
| 热更新 | 配置表/Lua可热更，无需重新发包 |
| 性能 | 中低端手机≥30fps，内存≤500MB |
| 网络 | 弱网环境下不崩溃，离线操作本地缓存 |
