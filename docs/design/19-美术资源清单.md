# 文档十九：美术资源清单

> 版本：V0.1.0-alpha
> 关联：文档一（美术风格规范 / 宠物动画状态）、文档二~文档十三（各系统策划）

## 19.1 文档目的

本文档基于既有策划案（文档一~文档十八）梳理**所有需要产出的美术/动效资源**，按系统模块归类，标注每项的数量、规格、来源章节，供美术（含 AI 出图 + 人工精修）、动效、UI 三方排期与验收使用。

> 美术量产方式（文档一 1.4）：AI 出图（Midjourney/SD 等）生成基础素材 → 人工精修：角色/宠物、建筑/装饰、UI、地图、动画帧与特效，统一 Q 版可爱风美术规范。

## 19.15 交付与验收备注

1. **统一规范优先级最高**：所有资源须满足文档一 1.5 的 Q版可爱风基线，跨模块复用（如地图/非遗插画/装饰）需风格一致。
2. **数量口径**：装饰首版 50~80 个（文档三 3.7）、城市 300~400 个（文档二 2.5）为区间值，最终以配置表（文档十六）为准。
3. **动态/特效**：石灯笼发光、假山流水、风铃、秋千、猫爬架、宠物 7 状态动画、信件逐字显现等需在动效排期单列。
4. **待策划补充项**：34 省省花清单（影响记忆翻牌与护照配图）、清明稀有鱼具体种类、稀有材料具体图标清单。
5. **资源命名**：建议按 `模块_编号_状态`（如 `pet_chai_idle`、`crop_wheat_03`）规则，便于热更与配置表（文档十六）字段对齐。
